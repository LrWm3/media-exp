# Repository Guidelines

## Branches & commits

- Branch names follow `<type>/<issue-key>-<description>` or `<type>/<short-description>` (e.g., `task/RE-13074-isolate-agent-skill`).  
- Commit messages follow linux commit style: `scope: <description>` and reference the relevant Jira issue when appropriate.
- Add details to most relevant `CHANGELOG.md` if one is found.
- Commit code changes in logical chunks with clear messages as you work by default.
